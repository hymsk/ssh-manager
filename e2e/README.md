# E2E 测试

基于 Playwright 的端到端回归测试，直接驱动真实浏览器操作界面。

## 前置

```bash
pip install playwright
python3 -m playwright install chromium
```

## 运行

先启动后端与前端（开发模式或单进程生产模式均可）：

```bash
# 方式一：开发模式
npm run dev:server     # :8899
npm run dev:web        # :5173
python3 e2e/plans.py http://localhost:5173

# 方式二：单进程生产模式
cd web && npm run build
cd ../server && npm start        # :8899
python3 e2e/plans.py http://localhost:8899
```

脚本会自行创建并清理测试数据，退出码非 0 表示有断言失败。

## 用例

`plans.py` — 执行计划卡片全流程：

| # | 用例 | 说明 |
| --- | --- | --- |
| 1 | 新建计划 | 模态框、目标主机选择、保存 |
| 2 | 编辑计划 | 字段回填、修改持久化 |
| 3 | 切换启用/暂停 | 状态变更且**卡片位置不跳动** |
| 4 | 快速连点 | 同一位置连点只影响同一张卡片 |
| 5 | Cron 预览 | 下次执行时间预览与保存 |
| 6 | 无效 Cron | 给出错误提示 |
| 7 | 表单校验 | 未选主机时拦截并提示 |
| 8 | 立即执行 | 产生逐机结果且状态正确 |
| 9 | 删除计划 | 列表同步 |
| 10 | 控制台 | 无意外报错 |

## 为什么覆盖「位置不跳动」和「快速连点」

早期版本按 `enabled` 排序计划列表，点击切换后卡片会立即重排到别的位置。
用户快速点击同一位置时，第 2、3 次点击会落到**另一张卡片**上，表现为
「切换按钮乱跳、点了没反应或切换错计划」。用例 3、4 专门锁定该回归。
