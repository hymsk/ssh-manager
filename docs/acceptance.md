# 验收清单

本项目已按需求实现以下能力，并逐项本地验证。

## 界面（三栏卡片式）

- [x] 顶部工具栏：在线/异常计数、探测间隔提示、刷新状态
- [x] 左侧 SSH 主机**小卡片**：名称、`user@host:port`、状态、延迟、最后探测、标签
- [x] 卡片内直接操作：终端 / 执行 / 配置 / 立即探测 / 删除
- [x] 卡片多选，底部出现「已选 N 台 / 批量执行 / 取消」
- [x] 一键「选中全部在线」
- [x] 中间区域 Tab：终端 / 批量执行 / 执行状态 / 执行记录
- [x] 右侧执行计划**小卡片**：启用状态、调度描述、目标数量、下次执行、命令摘要
- [x] 左右两栏均可收起

## 30 秒自动探测

- [x] 启动后立即探测一次
- [x] 之后每 30 秒探测一次（后端定时，不受浏览器后台节流影响）
- [x] 新增/编辑主机后立即探测
- [x] 卡片「⟳」手动立即探测
- [x] 状态机：未知/探测中/在线/不稳定/离线/认证失败/超时/异常
- [x] 连续 2 次失败才判定离线，恢复后自动回到在线并清零计数
- [x] 状态变化通过 WebSocket 实时推送到前端

## 批量执行

- [x] 选择多台主机后批量执行
- [x] 支持 Shell 命令与 Shell 脚本
- [x] 内置命令模板（巡检/服务/维护/备份/发布），支持变量替换
- [x] 并发数量、单机超时、失败重试次数可配置
- [x] 「失败后继续执行其他主机」开关
- [x] 「自动跳过离线主机」开关，跳过的主机标记为 `skipped`
- [x] 执行前提示非在线主机数量
- [x] 可同时「保存为执行计划」

## 逐机状态汇报

- [x] 顶部汇总：总计 / 成功 / 失败 / 执行中 / 等待 / 跳过
- [x] 每台主机独立一行：状态、重试次数、退出码、耗时
- [x] 点击展开：开始/结束时间、耗时、退出码、重试次数、错误原因
- [x] 标准输出与错误输出分栏显示
- [x] 失败主机可单独「重试此机器」
- [x] 全部失败可「重试失败」批量重试
- [x] 运行中可「取消任务」
- [x] 按状态筛选（全部/成功/失败/执行中/等待）
- [x] 导出 CSV 执行报告

## 执行计划

- [x] 计划小卡片：执行 / 配置 / 记录 / 暂停 / 启用 / 删除
- [x] 调度方式：仅手动 / Cron / 固定间隔
- [x] Cron 表达式支持与下次执行时间预览
- [x] 计划复用批量执行的并发/超时/重试/跳过策略
- [x] 到点自动触发，触发方式记为 `cron` / `interval` / `manual`
- [x] 计划执行结果写入执行记录，可回溯

## 执行记录

- [x] 记录列表：任务名、状态、成功/失败数、开始时间、触发方式
- [x] 点击查看该次任务的逐机结果与日志
- [x] 清空记录

## 安全

- [x] 密码/私钥 AES-256-GCM 加密存储
- [x] 接口不回传密钥，仅返回 `hasSecret`
- [x] 主机指纹 TOFU 校验，指纹变化直接拦截并标记 `error`
- [x] 主密钥可通过 `SSH_MANAGER_KEY` 注入，否则落盘 `DATA_DIR/key`（0600）

## 双形态

- [x] 浏览器：`web` + `server` 两进程，Vite 代理 `/api` 与 `/ws`
- [x] 后端托管 `web/dist`，单进程部署时可直接访问前端
- [x] 桌面：Tauri 2 壳复用同一前端，`beforeDevCommand` 自动拉起后端
- [x] 桌面生产模式 sidecar 启动后端并在退出时回收

## 本地验证记录

| 项 | 结果 |
| --- | --- |
| 后端类型/依赖 | 正常运行，`/api/health` 返回探测配置 |
| 探测：正常主机 | `online`，记录延迟与指纹 |
| 探测：主机下线 | 1 次失败 → `unstable`；2 次 → `offline`（原因：连接被拒绝） |
| 探测：主机恢复 | 自动回到 `online`，失败计数清零 |
| 指纹校验 | 模拟主机换 key 后连接被拒绝，状态 `error` |
| 批量执行（成功） | 全绿，run=`success`，逐机 rc=0 与 stdout 正确 |
| 批量执行（失败+重试） | run=`failed`，逐机 `failed`、retry 计数正确 |
| 批量执行（混合） | 一成功一超时，run=`partial`，逐机状态各自独立 |
| 跳过离线 | 离线主机 `skipped`，其余正常执行 |
| 重试失败 | 生成新 run，仅包含失败主机 |
| Cron 调度 | 计划在整分钟自动触发，`trigger=cron`，结果 `success` |
| 交互式终端 | WS 建立 PTY，输入回显正常 |
| WebSocket 事件 | `run_started`/`run_host`/`run_finished`/`host_status` 正常推送 |
| 前端构建 | `tsc -b` + `vite build` 通过 |
| 前端端到端 | Playwright 无控制台错误，卡片/批量执行/逐机结果/计划/记录全部可用 |
| 单元测试 | `npm test` 6/6 通过 |
